## 二、这次更新在做什么（人话版）

1. **会话日志上传 + 桌面端产品分析**：设置里新增「会话日志上传」偏好；桌面端通过 OTel 上报产品分析（字节限量、退出前取消导出、脱敏安装参数）。
2. **日程（Schedule）改成可选插件包**：日程开关以"可选 bundle"形式发布，插件管理器里成组开关，日程行在插件页可见。
3. **Windows 沙箱 ACL**：新增"ACL 拒绝"诊断技能；修复继承 ACL 的修复逻辑（保留属主、失败即停并留诊断报告）。
4. **Windows 界面细节**：窗口标题栏（caption）与浮层、对话框、全屏之间的间距与遮挡问题一批修复（含 Explorer 打开路径窗口不可见的问题）。
5. **聊天界面动效与状态**：运行中状态恢复完整；转写区下方加了"鲸鱼尾巴"动画；进程行 shimmer 统一、间距收紧。
6. **插件管理器**：安装示例按钮居中、注册表键盘选择与焦点反馈、刷新反馈与插图、IME 提交防抖、自动化任务行改名与图标。
7. **会话恢复更稳**：恢复过程中容忍"待定"的工具结果；失败步骤关闭前先结算待定工具结果。
8. **模型/搜索**：DeepSeek 网页搜索改用账号 token 鉴权（账号路由会话）；一次性清除失效的文件映射。
9. **跨平台兼容**：Safari/WebKit 的 JSON 原生构造器文本格式兼容；macOS 签名版的麦克风权限；Windows 安装包锁竞争修复。
10. **大量测试与文档**：33 条测试、29 条文档（含 .agents/notes 的设计记录）。
