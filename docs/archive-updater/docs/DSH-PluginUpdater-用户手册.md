## 1. 产品简介

### 1.1 什么是 DSH插件管家？

**DSH插件管家**（原名 DSH 插件升级管理工具）是一款独立运行的桌面应用，用于管理 DeepSeek Harness（DSH）生态下的插件。

**关键特性：**

- **独立运行**：不依赖 DSH Agent 本体进程，纯桌面工具
- **智能扫描**：自动识别插件目录下所有已安装插件
- **插件市场**：内置官方插件目录（2189+ 款插件），支持分类筛选、关键词搜索、排序、一键安装
- **组合包**：94 个行业预制组合包（医疗/法律/金融/教育/电商等），一键部署整套解决方案
- **一键更新**：通过 npm registry 检测最新版本，快速下载更新
- **启停管理**：轻松启用/禁用插件，无需删除文件
- **安全卸载**：卸载前自动备份，支持随时回滚
- **MCP 服务管理**：集中查看与管控本地 MCP 配置，支持连通性预检
- **快照与离线打包**：导出/导入插件清单，支持无网络环境还原
- **双语界面**：中文/英文一键切换

### 1.2 技术架构

- **前端**：Vue 3 + TypeScript + Element Plus（WeUI 封装层）
- **后端**：Rust（Tauri 2.0）
- **UI 库**：WeUI 2.6 + 自定义 W* 组件
- **动效引擎**：GSAP 3.15
- **主题**：深色/浅色双主题，玻璃拟态设计风格

### 1.3 系统要求

- **操作系统**：Windows 10/11 或 Linux
- **内存**：≥ 4GB RAM
- **磁盘**：≥ 500MB 可用空间
- **网络**：需要访问 GitHub 和 npm registry（可通过代理配置解决）

## 2. 核心功能

### 2.1 插件扫描

启动时自动扫描已配置的插件目录。扫描结果包括：

- 插件名称、版本、描述
- 是否启用
- 是否有可用更新
- 插件类型（用户插件/内置插件/系统组件）

### 2.2 插件安装

支持两种方式安装插件：

1. **从市场安装**：在「插件市场」标签页中点击「安装」按钮
2. **从目录安装**：通过安装对话框选择目标 profile 目录

### 2.3 插件更新

- 自动检测更新：启动时或手动点击「检查更新」
- 批量更新：一键更新所有可更新插件
- 单插件更新：针对特定插件执行更新
- 更新前自动备份：确保可回滚

### 2.4 插件卸载

- 卸载前自动备份
- 稳健删除：处理只读文件、长路径、占用文件
- 备份管理：可查看和恢复历史备份

## 5. 组合包

### 5.1 什么是组合包？

组合包是一套预配置的插件集合，包含：

- 一组相关插件
- MCP 服务模板（含环境变量键名说明）
- 技能（Skill）定义

### 5.2 组合包类型

| 类型 | 说明 |
|------|------|
| 通用基础 | 基础能力组合，适合所有用户 |
| 行业预制 | 针对特定行业的完整解决方案 |
| 预设模式 | 不写入全局配置，生成会话预设建议文件 |

### 5.3 组合包安装流程

1. **浏览**：在「组合包」标签页点击卡片查看详情
2. **预检**：自动比对当前已安装插件，标注冲突项
3. **确认**：查看即将安装/覆盖/跳过的插件清单
4. **安装**：一键安装，事务保障（失败自动回滚）
5. **完成**：自动合并 MCP 服务模板到本地配置

### 5.4 安装事务保障

- **自动备份**：安装前备份将被覆盖的插件
- **失败回滚**：任一步骤失败自动恢复到安装前状态
- **半装恢复**：中断后重启自动检测并恢复
- **冲突预警**：安装前标注已知冲突插件

## 7. MCP 服务管理

### 7.1 什么是 MCP？

MCP（Model Context Protocol）是 DSH 生态中的模型上下文协议，用于连接 AI 模型与外部工具和服务。

### 7.2 管理功能

1. **服务列表**：查看所有已配置和已禁用的 MCP 服务
2. **连通性预检**：一键测试服务是否可达
   - stdio 模式：启动探活
   - streamable-http 模式：发送探测请求
3. **环境变量配置**：填写 Token/密钥等敏感信息
   - 加密存储在系统凭据库（Windows 凭据管理器）
   - 面板中掩码显示
4. **启用/禁用**：安全移除或恢复服务配置
5. **写入配置**：将修改应用到运行配置

## 8. 快照与离线打包

### 8.1 快照功能

**用途**：导出/导入当前已安装插件的清单（名称、版本、npm 包名）

**导出**：
- 生成 JSON 文件，包含所有插件信息
- 可用于备份或迁移

**导入**：
- 预览与当前目录的差异
- 标注缺失插件和版本不一致项
- 一键在线安装缺失插件

### 8.2 离线打包

**用途**：在无网络环境下还原插件环境

**导出打包**：
- 将全部插件目录打包为 ZIP 文件
- 包含所有依赖

**离线还原**：
- 导入 ZIP 文件
- 按快照记录版本精确还原
- 同名文件覆盖

### 8.3 使用场景

- 内网环境部署
- 跨机器迁移插件配置
- 系统重装后快速恢复
- 版本备份与回退

## 11. 常见问题

### Q1: 插件扫描后列表为空？

**原因**：未配置插件目录或目录路径不正确。

**解决**：
1. 打开「设置」→ 配置「默认插件目录」
2. 点击「扫描」重新加载

### Q2: 检查更新失败？

**原因**：网络问题或 npm registry 不可达。

**解决**：
1. 检查网络连接
2. 配置代理地址
3. 或切换到国内镜像源

### Q3: 更新时提示「文件被占用」？

**原因**：DSH Agent 本体正在运行，锁定了插件文件。

**解决**：
1. 关闭 DSH Agent 本体
2. 重新执行更新操作

### Q4: 如何恢复误删的插件？

**方法**：
1. 打开「设置」→「快照与离线包」
2. 查看历史备份
3. 选择备份进行恢复

### Q5: 组合包安装失败？

**可能原因**：
- 网络问题导致下载中断
- 插件冲突未解决
- 环境变量未配置

**解决**：
1. 查看错误提示
2. 检查冲突项
3. 重试安装（支持断点续传）

### Q6: MCP 服务连通性测试失败？

**排查步骤**：
1. 检查 URL 路径是否正确（通常以  结尾）
2. 检查鉴权配置（401/403 需配置 Token）
3. 检查服务是否正常运行
