快速开始

DSH 插件升级管理工具是一个独立运行的桌面程序，不依赖 DSH Agent 本体。它可以扫描您的插件目录，管理所有已安装插件的更新、启用、禁用和卸载。

系统要求

  • Windows: Windows 10 或更高版本（64位）
  • Linux: Ubuntu 20.04+ / Debian 11+（x86_64）
  • 网络: 可访问网络代理服务器

安装指南

Windows 安装

  1. 从下载页面获取最新的 .exe 安装包
  2. 双击运行安装程序
  3. 按照安装向导完成安装
  4. 从桌面快捷方式或开始菜单启动程序

Linux 安装

  1. 下载 .AppImage 文件
  2. 打开终端，添加执行权限：chmod +x DSH-PluginUpdater_*.AppImage
  3. 运行程序：./DSH-PluginUpdater_*.AppImage

基本使用

1. 指定插件目录

在顶部输入框中输入您的 DSH 插件目录路径，例如：C:\DSH\plugins

2. 扫描插件

点击「扫描」按钮，工具将遍历目录下的所有子文件夹，读取每个插件的 plugin.manifest.json 文件，列出所有已安装插件。

3. 检查更新

点击「检查更新」按钮，工具将通过网络代理访问 GitHub，检测每个插件的最新版本。有可用更新的插件将高亮显示。

4. 更新插件

对于有可用更新的插件，点击「更新」按钮即可开始更新。更新前会自动备份旧版本，更新过程中显示进度条。

注意：更新插件前建议关闭 DSH Agent 本体，避免文件占用导致更新失败。

插件清单规范

每个插件目录下需要包含一个 plugin.manifest.json 文件，用于描述插件的基本信息。

字段说明

字段类型必填说明
idstring是插件唯一标识符
namestring是插件显示名称
descriptionstring否插件功能介绍
github_repostring否GitHub 仓库地址
current_versionstring否当前版本号
enabledboolean否是否启用，默认 true
typestring否类型: plugin 或 agent-core

常见问题

Q: 工具提示"检查更新失败"怎么办？

A: 请检查网络连接是否正常，网络代理服务是否可访问。

Q: 更新插件时提示"文件被占用"？

A: 请先关闭 DSH Agent 本体，再执行更新操作。

Q: 如何恢复被误删的插件？

A: 工具在卸载和更新前都会自动备份，可在设置中恢复。
