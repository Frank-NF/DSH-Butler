## 1. 设计哲学与原则

### 1.1 设计目标

| 目标 | 描述 |
|------|------|
| 专业性 | 企业级工具应有的严谨与克制 |
| 易用性 | 新用户 3 分钟内完成首次插件更新 |
| 高效性 | 减少操作路径，提升日常使用效率 |
| 一致性 | 桌面端与官网视觉统一，降低认知成本 |

### 1.2 设计原则

1. **内容优先**：UI 服务于功能，不喧宾夺主
2. **渐进增强**：移动优先，从 320px 到桌面渐进展示
3. **明确反馈**：每个操作都有即时、清晰的反馈
4. **安全第一**：高风险操作（卸载/更新）需要二次确认
5. **透明可控**：用户始终知道当前状态和下一步操作

### 1.3 目标用户

- **主要用户**：DSH Agent 生态的插件开发者与管理者
- **技术背景**：中等技术素养，熟悉命令行操作
- **使用场景**：本地开发环境，单次操作可能持续较长时间

- 背景：`#FFFFFF`

- 边框：`1px solid #DCDFE6`

## 6. 交互与动效规范

### 6.1 按钮交互

| 状态 | 变化 |
|------|------|
| Hover | `transform: translateY(-1px)`, `box-shadow` 增强 |
| Active | `transform: translateY(0)`, 颜色变深 |
| Loading | 显示 spinner，禁用点击 |
| Disabled | 透明度 50%，无交互 |

### 6.2 列表交互

- Row Hover：背景色 `#F5F7FA`
- Row Click：选中状态 `#ECF5FF`
- 加载遮罩：半透明白色 `rgba(255,255,255,0.8)`

### 6.3 弹窗动画

- 进入：`opacity 0→1, transform scale(0.95)→1`, 时长 200ms
- 离开：`opacity 1→0, transform scale(1)→0.95`, 时长 150ms
