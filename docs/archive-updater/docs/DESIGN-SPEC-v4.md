## 2. 色彩系统（高对比版）

### 主色（靛蓝，两端统一）
| Token | 值 | 用途 |
|-------|------|------|
| `--brand` / `--primary` | `#6366F1` | 品牌主色、主按钮、激活态 |
| `--brand-2` / `--primary-light` | `#818CF8` | 链接、悬浮、强调文字 |
| `--brand-3` / `--primary-dark` | `#4F46E5` | 按下态、渐变深端 |

### 文字灰阶（v4 核心改动，WCAG AA）
深色主题（背景 `#0B0F19` / `#151C2C`）：

| Token | 旧值 | 新值 | 对比度 | 用途 |
|-------|------|------|--------|------|
| `--fg` / `--text-primary` | #f8fafc | #f8fafc | 16.8:1 | 标题、主文字 |
| `--fg-1` | #e2e8f0 | **#e8edf5** | 15.2:1 | 一级正文 |
| `--fg-2` | #94a3b8 | **#b6c2d4** | **7.2:1** | 二级正文（原 4.1:1 不达标）|
| `--fg-3` | #64748b | **#8da0b8** | **5.1:1** | 辅助说明（原 2.9:1 严重不足）|
| `--fg-4` | #475569 | **#64748b** | 3.0:1 | 仅装饰性文字、禁用态 |

浅色主题（背景 `#F1F5F9` / `#FFFFFF`）同步加深一档。

> **规则：正文级文字一律用 fg-2 及以上；fg-4 只用于禁用态，禁止承载信息。**

## 3. 组件与动效

| 层面 | 规范 |
|------|------|
| UI 组件 | 客户端最大化 WeUI 原生结构（W* 封装层），样式经 CSS 变量统一品牌化 |
| 动效引擎 | **GSAP 统一**（客户端已接入 `useMotion.ts`；官网引入同版本） |
| 动效原则 | 只动画 `transform` / `opacity`；时长 0.24s（hover）/ 0.3s（进场）；缓动 `power2.out`；尊重 `prefers-reduced-motion` |
| 标准动效 | 列表项 stagger 0.04s 上浮进场；弹窗 0.25s scale(0.96→1)+fade；toast 下滑入场 |
| 圆角 | sm 8 / md 12 / lg 16 / xl 20 |
| 玻璃拟态 | `blur(20px) saturate(160%)`，仅头部/浮窗/弹窗使用，正文卡片用实底保证可读性 |

## 4. 图标（小鱼）

以一条简洁小鱼为核心：靛蓝渐变主体（#6366F1→#818CF8）、圆润流线造型、白色眼睛点缀。
圆角方形底（squircle），多尺寸：32/128/256 + ico/icns。
风格与整体靛蓝深色方案协调，造型极简保证 16px 下可识别。
