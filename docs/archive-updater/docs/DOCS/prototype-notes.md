## 1. 品牌色演进

### 1.1 从靛蓝到橙红

| 版本 | 主色 | 辅助色 | 基调 |
|------|------|--------|------|
| v1-v3 | `#6366F1` 靛蓝 | `#818CF8` | 深科技风 |
| v4.1+ | `#F46123` 橙红 | `#F78A5E` | 工程温暖感 |

**选择橙红的理由**：
- 与蓝紫盾牌图标形成冷暖对比，视觉层次更丰富
- 在石墨底上比靛蓝更具辨识度
- 传递"活力、可靠、工具感"而非"AI/科幻"的刻板印象
- 浅色主题下对比度更优（WCAG AA）

### 1.2 配套色推导

```
主色:    #F46123  →  hsl(18°, 90%, 55%)
浅色端:  #F78A5E  →  明亮版，用于 hover/link
深色端:  #E04A0E  →  按下态，渐变终点
柔光:    rgba(244, 97, 35, 0.14)  →  背景填充
```

## 2. 主题切换策略

### 2.1 双主题架构

| Token | 深色 | 浅色 |
|-------|------|------|
| `--bg-page` | `#0B0F19` | `#FAFAFA` |
| `--bg-card` | `rgba(30,41,59,.72)` | `rgba(255,255,255,.85)` |
| `--fg` | `#F8FAFC` | `#0F172A` |
| `--fg-2` | `#94A3B8` | `#64748B` |
| `--border` | `rgba(148,163,184,.14)` | `rgba(148,163,184,.22)` |
| `--shadow` | `0 4px 24px rgba(0,0,0,.35)` | `0 4px 24px rgba(15,23,42,.1)` |

### 2.2 默认主题变更

- **之前**：dark（桌面工具类软件惯例）
- **现在**：light（更贴近日常使用场景，减少 eye strain）
- 用户可通过设置切换，偏好持久化到 localStorage

### 2.3 品牌光晕调整

```css
/* 深色模式：低饱和度橙红光晕 */
--brand-glow: rgba(244, 97, 35, 0.3);

/* 浅色模式：几乎不可见 */
.w-app::before {
  background: radial-gradient(...rgba(244, 97, 35, 0.12)...);
}
```

## 4. 设计决策记录

### Q: 为什么官网保持深色而客户端默认浅色？

**A**: 两者定位不同：
- 官网是营销/下载页，深色更符合开发者审美惯例，且有"技术感"
- 客户端是日常工具，浅色减少长时间使用的 eye strain

### Q: 为什么不用玻璃拟态？

**A**: v3 设计系统已明确去掉 glassmorphism：
- 玻璃模糊在低分辨率屏上模糊不清
- 增加 GPU 负担
- hairline 实线边框更清晰、更可预测

### Q: 为什么数字一律等宽？

**A**: 统计数据（插件数、stars、版本）混排不等宽数字会造成视觉跳动，等宽保证对齐。

### Q: 为什么按钮不用渐变？

**A**: 纯色按钮更果断、更符合工程工具气质。渐变属于装饰，这里不需要。
