  • 扫描本机插件目录，识别已装插件与 Agent 本体
  • 从市场安装/更新插件，更新前自动备份可回滚
  • 按行业装组合包：插件 + MCP 模板 + Skill 一次装齐
  • MCP 服务集中配置，密钥存系统凭据库
  • 导出插件快照、打包离线安装包，隔离环境两步部署
  • 启停本地 DSH Web 服务器，一键打开面板
