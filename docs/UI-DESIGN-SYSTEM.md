# DSH管家 界面设计系统（v1.0 · 2026-09-24）

> 适用对象：内嵌在 `src/web/` 里的那套 HTML/CSS/JS（无框架、无构建步骤，全部是模板字符串）。
> 定稿依据：ui-ux-pro-max 检索（Minimalism & Swiss Style + 桌面工具类 UX 规则）+ 旧版 v4.1
> 的视觉基因。 用户已拍板：**沿用橙红主色 + 补深色模式**；**危险操作走「计划弹窗 + 勾选确认」**。

## 1. 定位与风格

这是一个**本机运维控制台**，不是落地页、不是营销页。设计目标按重要性排序：

1. **一眼看懂现在有没有事** —— 状态、结论、下一步动作永远在最显眼处；
2. **动手前看得见后果** —— 任何写操作先摊开计划，危险动作要勾选确认；
3. **长时间盯着不累** —— 密度适中、对比度达标、深色模式可切；
4. **不像 AI 随手糊的** —— 不用 emoji 当图标、不用大圆角渐变堆装饰。

风格：**Swiss / 极简功能主义**。几何、克制、留白服务于信息层级；装饰性阴影与渐变一律不用。

## 2. 颜色令牌

原则：**语义令牌优先**（组件里绝不写死十六进制）；状态**永远不只靠颜色**表达（同时给文字或形状）。

## 3. 字体与排版

- UI 字体栈：`"Segoe UI Variable Text", "Microsoft YaHei UI", "PingFang SC", system-ui, sans-serif`
  （不引外链字体：桌面程序离线可用是硬要求；中文用系统字体最稳）
- 等宽：`"Cascadia Mono", Consolas, "SF Mono", monospace`，用于路径、哈希、日志
- 字号：正文 **14px** / 次要 **12.5px** / 标题 16px / 页面主标题 18px；正文行高 1.55 （低于 12px
  的字只允许出现在日志证据块里）
- 数字对齐：所有计数、耗时、体积用 `font-variant-numeric: tabular-nums`
- 字重只用 400 / 500 / 600，不用 700 以上

## 4. 布局

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏 52px：品牌 · 本体状态徽章 · 服务状态徽章 · 主题切换 · 刷新 │
├──────────┬───────────────────────────────────────────────────┤
│ 侧栏     │ 主区（最大宽 1040px，内边距 24px）                 │
│ 200px    │  页面标题 + 一句话说明                            │
│ 分组导航 │  卡片：结论 → 数据 → 动作 → 问题清单               │
│          │                                                   │
├──────────┴───────────────────────────────────────────────────┤
│ 底部任务条（只在有任务时出现）：步骤链 + 进度 + 取消           │
└──────────────────────────────────────────────────────────────┘
```

- 侧栏分组：**概览**（总览）/ **诊断**（环境与配置、DSH 本体、运行状态、插件、日志、体检报告）/
  **记录**（任务、回滚点）
- 每个页面固定节奏：标题区 → 结论卡（最显眼）→ 明细卡 → 动作区
- 响应式：< 900px 时侧栏收成 56px 图标栏；主区最小可用宽度 720px（桌面程序，不做手机布局）

## 5. 组件规范

| 组件          | 规范                                                                                                                                                                          |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 按钮          | 高度 32px（小号 26px）、圆角 8px、左图标右文字、间距 8px；主操作 `.primary`（橙底白字）、次操作默认（白底描边）、危险 `.danger`（红底白字或红字描边二选一，同一页面只用一种） |
| 状态徽章      | 圆点 + 文字（**色 + 字**双重编码），hover 显示解释                                                                                                                            |
| 卡片          | 1px 描边 + 10px 圆角、16px 内边距；标题右侧可挂计数 pill                                                                                                                      |
| 数据行 `.row` | 名称（左）+ 元信息（中）+ 动作（右，hover 才显形但键盘 Tab 可及）；整行可聚焦                                                                                                 |
| 问题条目      | 沿用「四要素」：原因 / 影响 / 建议（+ 证据可折叠）                                                                                                                            |
| 空状态        | 一句话说明 + 一个明确的下一步按钮，不留白板                                                                                                                                   |
| 弹窗          | 560px 居中、遮罩 `rgba(0,0,0,.45)`、Esc 关闭、焦点锁在弹窗内、打开时焦点落在首个可操作元素                                                                                    |
| 计划弹窗      | 标题 = 动作人话名；正文 = 有序步骤表 + 写前检查（error 级红、warn 黄）；底部 = 勾选框「我已了解上述步骤」+ 执行按钮（危险动作用红色）                                         |
| 进度条        | 4px 轨道 + 步骤链（灰/橙/绿/红）；可取消时显示取消按钮                                                                                                                        |
| 提示条 toast  | 右下角，4s 自动消失，成功/警告/错误三色，可手动关                                                                                                                             |

**图标**：一律内联 SVG（16px，`stroke-width` 1.6，`currentColor`），不用
emoji、不用图标字体。本仓只保留一套最小图标集（导航 + 动作）。

## 5.5 标志与 VI（2026-09-24 定稿）

**标志**：一只橙红小鲸鱼（朝右、圆头厚身、横向尾叶）。鲸鱼是"沉在深处慢慢游"的意象，
与"常驻后台、随叫随到"的产品性格对得上；橙红沿用品牌主色，一眼能认出是同一个产品。

| 资产                 | 文件                                                       | 用途                                    |
| -------------------- | ---------------------------------------------------------- | --------------------------------------- |
| 矢量母版（透明底）   | `icons/whale.svg`                                          | 设计源文件；改形状/配色从这里改         |
| 矢量母版（深色方砖） | `icons/whale-tile.svg`                                     | 带底板的版本，供需要方砖的场合          |
| 应用图标             | `icons/icon.ico` / `icons/icon.icns` / `icons/128x128.png` | 窗口、任务栏、安装包                    |
| 托盘图标             | `icons/tray.ico`（多尺寸）/ `icons/tray.png`               | 系统托盘；透明底、无方砖，16px 下最清楚 |

位图全部由 `python icons/generate.py` 生成（一份几何、两处产物）。**要改图标就改这个脚本， 不要手改
PNG** —— 否则下次重生成又被打回原样。

**配色**（与 §2 的语义令牌同源，不另起炉灶）：

| 角色      | 值        | 说明                               |
| --------- | --------- | ---------------------------------- |
| 鲸身      | `#F46123` | 品牌橙（`--brand`）                |
| 胸鳍      | `#C2410C` | 深一号，只在 ≥64px 的尺寸下出现    |
| 眼        | `#201D1A` | 深墨                               |
| 水柱/高光 | `#FFF0E8` | 奶油白                             |
| 方砖底    | `#1F1E1B` | 暖黑（深色版）；浅色备选 `#FBF6F2` |

**使用规矩**：

- 最小尺寸：托盘 16px、界面内 20px、应用图标 32px；**16px 下不画水柱与胸鳍**（会糊成脏点）。
- 留白：标志四周至少留出"鲸身高度的 1/4"，不要贴着边或压到文字。
- 界面里的品牌位（顶栏左上、DSH 页面悬浮条的「管家」按钮）用同一只鲸鱼，
  但按尺寸简化（只有身体+眼睛）；**不做描边版/单色版之外的变体**。
- 不要：给它加投影/外发光、拉长压扁、旋转、换色（除已有的橙红两档）。

## 6. 动效

- 时长：hover/按下 120ms；浮层出现/消失 200ms；进度条 250ms
- 缓动：`cubic-bezier(.2,.7,.3,1)`
- 只动 `opacity` / `transform`；不动
  `width`/`height`/`left`（进度条宽度是唯一例外，它本身就是进度语义）
- 弹窗：`opacity 0→1` + `translateY(6px)→0` + `scale(.98)→1`
- `@media (prefers-reduced-motion: reduce)` 下全部动画归零，直接呈现终态
- 不用 GSAP：这套界面没有时间轴类需求（列表、弹窗、进度条三类），引入徒增体积

## 7. 反模式（评审时逐条对照）

1. ❌ emoji 当图标、图标字体、装饰性插画
2. ❌ 只靠颜色表达状态（红点没有文字说明）
3. ❌ 危险动作点了就干（必须过计划弹窗 + 勾选）
4. ❌ 按钮禁用却不说明为什么（现在起一律在按钮旁给一行原因）
5. ❌ hover 才有、键盘够不到的操作
6. ❌ 正文小于 12px、灰字对比度低于 4.5:1
7. ❌ 一个页面里多种危险按钮样式混用
8. ❌ 表单只给 placeholder 当标签
9. ❌ 加载时布局跳动（预留空间，空态用固定高度）
10. ❌ 长路径/长哈希撑破布局（一律 `word-break` + 单行省略 + 悬浮给全量）

## 8. 交付前检查清单

- [ ] 键盘可走完一遍：导航 → 列表 → 动作 → 弹窗 → 确认 → 关闭（焦点可见）
- [ ] 浅/深两套配色下，正文与次要文字对比度均 ≥ 4.5:1
- [ ] `prefers-reduced-motion` 下无动画
- [ ] 写操作全部经计划弹窗；error 级写前检查会拦住执行按钮
- [ ] 空态、加载态、错误态三态齐全（不留空白）
- [ ] 长文本（路径、哈希）不撑破容器
- [ ] 无 emoji 图标；所有图标来自统一 SVG 集
- [ ] 1920×1080 与 1280×800 两种窗口尺寸下均不出现横向滚动条

## 9. 实施与审计记录（2026-09-24）

**代码落点**：`src/web/styles.ts`（令牌与组件样式）、`src/web/markup.ts`（骨架 + 侧栏提示 +
弹窗宿主）、 `src/web/client.ts`（九页路由 + 计划确认弹窗 + 全部写操作入口）、`src/api/server.ts` 的
`POST /api/plan`。

**design-taste-frontend 审计结论**：该技能自述适用范围是落地页 / 作品集 /
改版，「不适用于仪表盘、数据表、多步产品界面」， 因此只取其反廉价通则逐条对照 —— 无 emoji 图标、无
AI 紫渐变、状态不靠颜色单独表意、危险动作必须二次确认， 均通过。真正改掉的三处问题如下表。

| 审计项     | 实测                                                                                                                                                | 处理                                                                                                                     |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 令牌对比度 | 脚本算 28 组组合。**唯一不合规**：`--brand` #F46123 当文字用在 `--brand-weak` 上只有 **2.79:1**（活动导航项、计划弹窗步骤序号、进度条"进行中"步骤） | 新增 `--brand-text`（浅色 #B23C0B = 5.18:1，深色沿用 #FF8A5B），三处改用新令牌；`--brand` 只留给图标、进度条等非文字元素 |
| 字号自查   | 导航分组与侧栏提示是 11.5px，违反本规范"正文不低于 12px"                                                                                            | 提到 12px（计数 pill、`tag` 一并跟进）                                                                                   |
| 键盘可达性 | Playwright 实跑：Tab 三次后焦点环清晰可见                                                                                                           | 另给任务行补 Enter / 空格打开详情（此前只有内层按钮可达）                                                                |

**实跑验证**（Playwright + Chromium
打本机服务，七个页面/状态）：概览、任务、插件、计划弹窗、回滚点、
深色插件页、深色焦点态全部渲染正常，**console 错误 0 条**。
