# 重装系统与换机恢复

> 2026-09-27 起因：用户问「重装系统怎么恢复全量配置，管家里好像只有备份」。
> 查证发现**真缺口**：旧搬移包只带配置与插件清单，**密钥一个都没带** ✗ —— 恢复完会出现「配置齐全但连不上模型、连不上服务器」的半残系统。已补齐。

## 一、重装前必须做的 5 件事

| # | 做什么 | 为什么 |
| --- | --- | --- |
| 1 | 管家 → 记录 → **数据搬家 → 导出（选「全量」）** | 一次带走：DSH 配置、插件清单、**API 凭据**、技能、会话、附件、**storages（记忆）**、管家设置与回滚点 |
| 2 | 把导出的「DSH搬移包-日期」**整个文件夹复制到移动硬盘或网盘** | 包在系统盘上，重装就没了 |
| 3 | 单独备份 **`C:\Users\<你>\.ssh`** 整个目录 | SSH 私钥**不在** `~/.dsh` 里，搬移包带不走；丢了就连不上服务器与 GitHub |
| 4 | 截图或记下：GitHub 账号与 2FA、服务器地址、`~/.dsh-butler/config.json` 里的自定义项 | 换机后要重新登录 |
| 5 | 清点 `G:\` 等项目盘里的东西（本手册不管项目文件） | 别只备份了 DSH 忘了项目 |

## 二、新系统恢复 6 步

1. 到 <https://dsh.huilinsh.cn> 下载 `DSH-Butler-*-win-x64.zip`，解压到任意目录，双击 `dsh-butler.exe`；
2. 先把搬移包放到本机（例如 `D:\DSH搬移包-20260927-161058`）；
3. 管家 → 记录 → **数据搬家 → 导入**，选中包里的 `MANIFEST.json`；
4. 导入完成后回「一键部署」跑一次（装插件依赖，约 100 MB，几分钟）；
5. 把备份的 `.ssh` 放回 `C:\Users\<你>\.ssh`，并检查权限（只允许自己读写）；
6. 重启管家 → 打开「诊断 → 统计」与「体检报告」，确认没有错误项。

## 三、包里有 / 包里没有

| 类别 | 内容 |
| --- | --- |
| **包里有** ✓ | DSH 主配置（含 MCP）· 插件清单与锁 · cordis.patch.yml / cordis.yml · .npmrc · **API 凭据 .credentials.yaml** · 模型通道 / SSH 隧道 / jev / git-forge / 聚合插件配置 · 用量统计 · **技能** · **storages（记忆与向量数据）** · 会话记录 · 附件 · 管家设置与回滚点索引 |
| **包里没有** ✗ | `~/.ssh`（自带备份）· 浏览器书签与登录态 · 其他软件配置 · `G:\` 等项目文件 · 系统级环境变量 |

## 四、恢复后的验收清单

- [ ] 管家顶部两个状态点都是绿色（本体 + 服务）
- [ ] 插件市场里已装插件数量与重装前一致，且能显示「已装」
- [ ] 能正常与模型对话（**密钥生效**的最终证据）
- [ ] `gh auth status` 显示已登录；`git push` 可用（GitHub 通道）
- [ ] `ssh suozi-cc 'echo ok'` 免密可用（服务器通道）
- [ ] 「诊断 → 统计」里能看到历史任务，说明账本也恢复了

## 五、一句话原则

**搬移包 = DSH 与管家的全部身家；`.ssh` 与项目盘 = 它管不到的部分，要自己备份。**
两者都备齐，换机就是「装 zip → 导入 → 重启」三步。
