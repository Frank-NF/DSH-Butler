DSH 管家 · 使用帮助

一句话：管家是 DSH 的本地运维台 —— 装、修、更新、守护，四件事都在一个窗口里。

一、第一次用

  1. 双击 dsh-butler.exe 打开管家（免安装，绿色包）。
  2. 第一次会自动部署 DSH 本体并把服务跑起来；顶部两个状态点分别是「本体」与「服务」。
  3. 两个点都是绿的就可以点右上角「进入 DSH」开始用。

二、日常最常用的五件事

  • 装插件：插件市场 → 搜关键词 → 点安装（装前会自动留回滚点）。
  • 修问题：环境与配置 / 运行状态页会直接告诉你哪里不对，多数问题旁有「一键修」。
  • 更新插件：插件市场右上角「全部更新（含验证）」一次更完所有能更新的（插件页上有个指路按钮）；只想更一个就点那个插件自己的「更新」。
  • 更新本体：总览页和本体页只有一个按钮，管家自己判断该干什么 —— 有新版本就"停服 → 拉取 → 重建 → 重启"一次做完，只差重建就直接重建；不用先点一个再点另一个。
  • 想知道新版本改了啥：DSH 本体页的「本体更新日志」先给中文的改动统计（新功能 / 修复 / 性能 / 重构 / 文档 / 测试各多少条）加头几条，点「看全部」在弹窗里滚动看全部，点「用 AI 中文总结」让 AI 助手用中文讲清这次更新改了什么（要先在 AI 助手页配好模型）；本机还没有上游记录时，先点「拉取上游更新记录」（只拉标签，不动工作区、不改 HEAD）。
  • 出事了退回：记录 → 回滚点，选一个时间点还原（动手前可先看「影响预览」）。
  • 备份与搬移：记录 → 数据搬家，导出搬移包（换机器时在新机器导入）。

三、它还会自己干活

设置 → 定时任务与备份 里可以设定：多久体检一次、多久备份一次、多久查一次更新。

发现的问题会进总览页的「管家提醒」卡片，托盘图标悬停也能看到条数。

问题解决了（比如插件都更新完了）它会自己把那条提醒撤掉，不用手动清；历史条目也能在卡片上「清空提醒」。

四、出问题怎么求助

体检报告页右上角「导出诊断包（脱敏）」：把体检结论、环境、依赖冲突、日志错误行打成一个文件夹。

家目录会变成 ~、用户名变成 %USER%、密钥与邮箱全部打码，并且导出后会回读自检一遍，发现残留就不让导出。

把它发给别人就能一次性说清现场。

五、想知道谁改过什么

记录 → 任务 → 右上角「写操作审计」：按时间倒序列出每一次写操作（谁触发的、改了什么、成没成、留下哪个回滚点）。

点「导出审计」可以得到 Markdown 与 CSV 两份文件。

六、技能与配置的版本管理

数据搬家页 →「技能快照」会在你的技能目录（~/.dsh/skills）里做一次本地 Git 提交。

「查看快照」看历史，「回退到某次快照」可回退（动手前会先把当前改动 stash 起来，不丢东西）。

想跨机同步，给这个仓库加个 remote 再 push 即可。

七、网络不好怎么办

设置 → 网络与高级：npm 安装源可以直接下拉选（阿里云 / 官方 / 腾讯云 / 华为云，或自己填）。

「测安装源速度」会并发测一遍，告诉你哪个最快。

离线安装：插件市场有「离线安装」，把 tgz 拖进来就能装。

八、常见疑问

  • 管家会不会偷偷改系统？所有写操作都会先给你看计划，确认后才执行，并且大多会留回滚点。
  • 数据在哪？管家的配置在 ~/.dsh-butler，DSH 的数据在 ~/.dsh，都跟着你自己的用户目录走。
  • 端口对外开了吗？没有。服务只监听本机回环地址。
  • 和官方桌面端一起装会不会打架？管家检测到官方桌面端在跑时会自动退成运维模式，不抢窗口与托盘。
  • 想关掉 DSH 服务？右下角那条悬浮工具条上就是「启动 / 停止 / 重启」，DSH 界面和管家界面都有同一条；首页「DSH 已就绪」卡片里也有一个「停止服务」。
  • AI 助手的地址与密钥要手抄吗？不用：AI 助手页里有「从 DSH 导入」，DSH 里已经配好的通道点一下就搬过来（密钥只在本机文件之间复制，页面上只看得到掩码）。
  • AI 的地址、模型、密钥在哪儿改？AI 助手页右上角「API 设置」（弹窗里）：填地址 / 模型 / 密钥，或点里面的「从 DSH 导入」一键把 DSH 已配好的通道搬过来（密钥只在本机文件之间复制，页面上只看得到掩码）。页面主体只留对话，不再一进来就是一张表单。
  • 插件装完了却没生效？插件页顶部的「装了却没加载」会告诉你：DSH 会因为插件声明的内部包版本和本机运行时对不上，把整包跳过（包在、代码在，就是不加载）。确认你信任这个插件后点「允许运行」，管家会给它开一张只针对这个版本的通行证（写在 profile 的 compatibility.json 里，不动依赖、不动生效名单），再按提示点「重启 DSH 服务」就生效；点「收回通行证」可随时撤销。
  • 找不到 DSH 本体，或者想指定源码目录？设置 →「DSH 源码目录」：上半截写清现在实际用的是哪个目录、是靠什么找到的；下面那栏填源码根目录（例如 G:/DeepSeek_Harness，注意不是 apps/cli、也不是 profile 目录），留空 = 回到自动搜索，改完点「保存设置」立刻生效，不用重启。
  • 界面一直停在「127.0.0.1 拒绝连接」怎么办？管家每半分钟看一眼界面还在不在，发现跑偏了会自己重新加载（一分钟内最多救一次）；也可以右键任务栏上的管家图标点「回到管家」。

九、命令行（给爱折腾的人）

管家自带只读诊断命令，例如 doctor 与 env probe，加 --json 可给脚本消费。
